BIRTHDAY LOVE WORLD WEBSITE ❤️

1. Extract the ZIP.
2. Open the folder in VS Code.
3. Use Live Server and open index.html.

EDIT script.js:
- password: change the secret password
- friendName: birthday person's name
- letter: your complete typewriter letter

Replace assets/photo1.svg through photo6.svg with your six photos. If using JPG/PNG, update the six image paths in script.js.

The uploaded 55259.mp4 is included as assets/theme.mp4 and is used as the looping visual background. Its audio was extracted to assets/music.mp3, giving the website one continuous background music track. Replace music.mp3 if you want another song.
